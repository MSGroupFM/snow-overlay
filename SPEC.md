## Реализация

Симуляция для настольных приложений находится в `core/`. Оболочки передают ей границы видимых окон, прямоугольник дисплея и положение указателя. Web-виджет реализует аналогичную симуляцию в Canvas 2D и получает геометрию из DOM. Сугробы привязаны к идентификатору поверхности. Система сохраняет координаты снежков относительно этой поверхности.

Первичная цель совместимости — macOS 12 и новее и Windows 10 22H2 / Windows 11, 64 бита. Проверку разрешений macOS, нескольких мониторов, масштабирования Windows, панелей системы и полноэкранного режима выполняем на соответствующих ОС. Публичные сборки проходят проверку подписи и запуск с включённой системной защитой. Для Windows предпочтителен Microsoft Store с MSIX. Для прямой загрузки используются доверенная подпись Windows или Developer ID и notarization на macOS.

Первый релиз включает сам эффект и управление им. Платежи и лицензирование требуют отдельного продуктового решения.
